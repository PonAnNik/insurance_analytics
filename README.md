# Insurance Portfolio Analytics

Учебный проект по анализу страхового портфеля с использованием Oracle SQL и Python.

## О проекте

Проект представляет собой небольшую аналитическую систему для работы с синтетическими данными страховой компании.

Данные генерируются с помощью Python, хранятся в реляционной базе данных Oracle и анализируются с использованием SQL и pandas. Для визуализации результатов используются Python и matplotlib.

## Цель проекта

* разработать связанную реляционную модель страхового портфеля;
* сгенерировать синтетические данные с заданными бизнес-правилами;
* реализовать ограничения целостности данных;
* проверить корректность сгенерированных данных;
* выполнить аналитические запросы в Oracle SQL;
* передать подготовленные данные в Python;
* провести дополнительный анализ с использованием pandas;
* визуализировать результаты.

## Структура данных

Основные таблицы:

* `CLIENT` — информация о клиентах;
* `POLICY` — страховые полисы;
* `PAYMENT` — платежи по полисам;
* `CLAIM` — страховые случаи.

Также используются справочные таблицы для типов полисов, типов страховых случаев и статусов.

Основные связи между таблицами:

```text
CLIENT
   │
   └── POLICY
          │
          ├── PAYMENT
          │
          └── CLAIM

```

## Генерация данных

Синтетические данные генерируются в Jupyter Notebook `python/python_create_data/create_data.ipynb`.

При генерации учитываются связи между сущностями и бизнес-правила предметной области. Например:

* клиент может иметь несколько полисов;
* полис имеет определённый срок действия;
* платежи относятся к конкретному полису;
* дата платежа не превышает дату начала полиса;
* страховой случай относится к существующему полису;
* дата страхового случая находится в периоде действия полиса;
* тип страхового случая зависит от типа страхования;
* сумма страхового случая зависит от соответствующих параметров полиса и типа случая.

## SQL

SQL-часть проекта разделена на несколько скриптов.

### `01_create_tables.sql`

Создание таблиц и структуры базы данных.

### `02_constraints.sql`

Добавление ограничений целостности данных:

* первичные ключи;
* внешние ключи;
* `CHECK`-ограничения;
* другие ограничения, необходимые для корректности данных.

### `03_check_data.sql`

Проверка корректности сгенерированных данных с помощью SQL-запросов.

Проверяется соблюдение бизнес-правил и отсутствие некорректных связей и значений.

### `04_analysis_queries.sql`

Аналитические SQL-запросы.

Файл содержит несколько отдельных запросов для анализа данных, а также основной запрос, формирующий итоговую аналитическую выборку для дальнейшей обработки в Python.

В SQL выполняются операции фильтрации, объединения таблиц, группировки и агрегирования данных. В частности, рассчитываются показатели страхового портфеля и `loss_ratio`.

## Python

Python используется для генерации данных, дополнительного анализа и визуализации.

### `main.ipynb`

Основной Notebook аналитической части проекта. Загружает подготовленные данные, вызывает функции анализа и визуализации.

### `analysis.py`

Содержит функции дополнительного анализа данных с использованием pandas.

### `visualization.py`

Содержит функции построения графиков с использованием matplotlib.

## Аналитическая часть

Проект позволяет исследовать страховой портфель по различным измерениям, включая:

* тип страхования;
* регион;
* количество и сумму страховых случаев;
* страховые премии;
* `loss_ratio`.

Часть аналитики выполняется непосредственно в SQL, после чего подготовленная выборка используется в Python для дополнительной обработки и визуализации.
